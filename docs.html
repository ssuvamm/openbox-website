OpenBox Documentation

Everything you need to install, configure, and get the most out of OpenBox.

Getting Help

Community Support

OpenBox is community-supported. The best place for help is the GitHub Discussions page.

Before Posting

Always run openbox doctor and include the output in your post. Check the troubleshooting section below — many issues are already documented with fixes.

Bug Reports

When reporting a bug, please include:

  • Hardware: e.g. UGREEN NAS / Hostinger VPS / WSL2 / Beelink Mini PC
  • OS: e.g. UGOS Pro / Ubuntu 22.04 — paste uname -a output
  • OpenBox version: openbox --version
  • Module failing: e.g. seerr / jellyfin / qbittorrent / dashboard
  • VPN provider: Surfshark / ProtonVPN / Mullvad / none (if media-related)
  • What happened: exact error message, not a paraphrase
  • Logs: sudo openbox logs <module>
Security — Never Share These

Do not post full license keys, plaintext passwords, API keys (Sonarr, Radarr, Prowlarr, Anthropic), VPN credentials, WireGuard private keys, or full .env files. Share last 4 characters of license key only.

  • Debian-based: Ubuntu 22.04+, Debian 12+, Linux Mint, Pop!_OS, Raspberry Pi OS, Kali
  • RHEL-based: Rocky Linux, AlmaLinux, Fedora, RHEL, CentOS Stream
  • Arch-based: Arch Linux, Manjaro, EndeavourOS

Outbound Access Required

Your server needs outbound HTTPS to:

  • openbox.crushcodeworks.com — release downloads
  • webhook.openbox.crushcodeworks.com — license validation (optional, Pro feature)

NAS Requirements

  • UGREEN NASync NAS (DXP2800, DXP4800, or similar Docker-capable model)
  • 4 GB+ RAM (8 GB recommended, 16 GB for media + photo modules)
  • SSH access enabled
  • VPN subscription (only if enabling Media module)

Installing on a VPS

# Step 1: Connect to your server
ssh root@YOUR_SERVER_IP

# Step 2: Update the system
apt update && apt upgrade -y

# Step 3: Run the installer
curl -fsSL https://raw.githubusercontent.com/ssuvamm/openbox-website/main/install.sh | sudo bash

# Or inspect before running:
curl -fsSL https://raw.githubusercontent.com/ssuvamm/openbox-website/main/install.sh -o install.sh
less install.sh
sudo bash install.sh

Installing on UGREEN NAS

  1. Enable SSH: Control Panel → Terminal → Enable SSH Service → Restart NAS
  2. Connect via SSH: 
    ssh your-admin-username@192.168.1.17
  3. Verify Docker: 
    docker --version
docker compose version
# If Docker is missing:
curl -fsSL https://get.docker.com | sh
  4. Install OpenBox: 
    curl -fsSL https://raw.githubusercontent.com/ssuvamm/openbox-website/main/install.sh | sudo bash

Installing on WSL2 (Windows)

WSL2 is community-supported. Ubuntu from the Microsoft Store works best.

# Install Ubuntu from Microsoft Store, then:
wsl -d Ubuntu
curl -fsSL https://raw.githubusercontent.com/ssuvamm/openbox-website/main/install.sh | sudo bash
Docker on WSL2

WSL2 requires Docker Desktop installed on Windows, or you can install Docker inside WSL2 with curl -fsSL https://get.docker.com | sh. For the best experience, use Docker Desktop with WSL2 integration enabled.

Setup Wizard

The wizard runs automatically after installation. It configures:

  • Server Address — IP or domain of your server
  • Timezone — Format: Continent/City (e.g. America/New_York)
  • Module Selection — Toggle modules on/off with arrow keys + space
  • VPN Credentials — Required only if you enabled the Media module

First Login

After installation, open the dashboard at:

http://YOUR_SERVER_IP:8443

You'll be greeted with a bootstrap token. Copy it from the terminal output or run:

sudo openbox bootstrap-token

Dashboard Navigation

  • App Store — Enable/disable modules
  • Settings — Configure VPN, network, backups
  • Help — Docs, logs, support links

Finding App Passwords

Click any app tile in the dashboard — a modal shows the auto-generated username and password. These are saved in /opt/openbox/state/ as plaintext files.

Using Your Apps

OpenBox organizes apps into modules. Enable modules from the dashboard App Store.

Core Modules

  • Dashboard — OpenBox web UI on port 8443
  • Nginx Proxy Manager — Reverse proxy + SSL termination on ports 80/443
  • Portainer — Container management UI on port 9000

Media Modules

  • Jellyfin — Media server (port 8096)
  • Sonarr — TV show management
  • Radarr — Movie management
  • Prowlarr — Indexer manager
  • Lidarr — Music management
  • Bazarr — Subtitle management
  • qBittorrent — Torrent client
  • SABnzbd — Usenet client

Privacy Modules

  • Pi-hole — Network-wide ad blocking on port 8053
  • Vaultwarden — Password manager on port 8222
  • AdGuard Home — Alternative DNS sinkhole

Utility Modules

  • Uptime Kuma — Server monitoring
  • Grafana + Prometheus — Metrics dashboards
  • HomeHub — Browser-based home dashboard
  • Linkding — Self-hosted bookmarks
  • Actual Budget — Personal finance

Setting Up Your Network

Local Network Access

All apps are accessible at http://YOUR_SERVER_IP:PORT from devices on the same network.

WireGuard VPN

Enable the VPN module for remote access. Clients download a config file from the dashboard → VPN tab.

# On your phone/laptop, install WireGuard app, import the config file
# Connect from anywhere — all traffic goes through your home server

Tailscale

Enable Tailscale for zero-config remote access without port forwarding. Add your auth key in Settings → Remote Access.

Custom Domain + SSL

Nginx Proxy Manager handles SSL automatically. Point your domain's DNS to your server IP, then add a proxy host in NPM.

Media Stack Overview

The media stack is a suite of apps that work together to automatically find, download, and organize your media.

VPN Required for Media

The Media module requires a VPN subscription. OpenBox recommends Surfshark — affordable, fast for BitTorrent, and works with gluetun out of the box.

Flow

Seerr (request UI) → Prowlarr (indexer search) → Sonarr/Radarr (release detection) → qBittorrent/SABnzbd (download) → Jellyfin (playback)

First-Time Setup

  1. Enable the Media module in App Store
  2. Configure VPN credentials in Settings → Network → VPN
  3. Add at least one indexer in Prowlarr (Settings → Indexers → Add)
  4. Request a movie or TV show in Seerr

ARR Stack

The "ARR stack" (Sonarr, Radarr, Prowlarr, Lidarr, Bazarr) is auto-configured by OpenBox's arr-bootstrap script, which runs automatically when the media module starts.

ARR Bootstrap Does This

  • Generates stable API keys per app
  • Wires download clients (qBittorrent, SABnzbd) to each ARR
  • Creates quality profiles
  • Registers Prowlarr as indexer in Sonarr/Radarr/Lidarr
  • Configures FlareSolverr for Cloudflare-bypassing indexers
  • Self-heals on every openbox up

VPN Setup

Recommended: Surfshark

Surfshark wins on price (~$2.20/mo), speed (16× faster than ProtonVPN in real BitTorrent tests), and simplicity — all servers allow P2P.

Getting Your WireGuard Key

  1. Sign up → Surfshark
  2. My Account → VPN tab → Manual setup → Router → WireGuard
  3. Generate a key pair, copy the Private Key and Address
  4. Paste into OpenBox Settings → Network → VPN

Other Supported Providers

Tested: Surfshark ✓, ProtonVPN ✓

Should work (via gluetun): Mullvad, IVPN, Private Internet Access, NordVPN, ExpressVPN, Windscribe, HideMyAss, PureVPN, VyprVPN, PrivateVPN, Privado, PerfectPrivacy, AirVPN

VPN Kill Switch

gluetun (the VPN tunnel container) has a built-in kill switch. If the VPN drops, all media download containers lose internet access — your real IP is never exposed.

Indexers

Indexers tell Prowlarr where to search for torrents. OpenBox does not pre-configure any indexers — you choose based on your region and content.

Recommended Free Indexers

  • Jackett — Aggregates many public trackers
  • 2 Cathedra — Good general coverage
  • Ninja CENTRAL — Popular community indexer

Adding an Indexer

  1. Open Prowlarr at http://YOUR_IP:9696
  2. Settings → Indexers → Add → Choose type (Torznab for Jackett, or direct)
  3. Fill in the indexer URL and API key
  4. Test and save
Cloudflare-Bypassing Indexers

Some indexers use Cloudflare protection. OpenBox includes FlareSolverr in the media stack to automatically bypass this. Indexers that require Cloudflare will work automatically.

Usenet Setup

Usenet is faster and more reliable than public torrents for TV and movies, but requires a paid provider (~ $10/mo) and indexer (~$10/yr).

Provider + Indexer

  • Provider: Newshosting, Eweka, Easynews
  • Indexer: NZBgeek, Drunkenslug, DogNZB

Configuring SABnzbd

  1. Open SABnzbd at http://YOUR_IP:8080
  2. Add your Usenet provider in Settings → Servers
  3. Add your indexer in Settings → Indexers
  4. SABnzbd is automatically wired to Prowlarr by arr-bootstrap

Troubleshooting

Run the Doctor

sudo openbox doctor

This checks Docker, disk space, RAM, port conflicts, module health, and VPN status. Always run this first.

View Logs

# All modules
sudo openbox logs

# Specific module
sudo openbox logs jellyfin
sudo openbox logs seerr
sudo openbox logs qbittorrent

Restart a Module

sudo openbox restart media
sudo openbox restart dashboard

Common Issues

Dashboard shows "Connection Refused"

The dashboard container might not be running:

sudo openbox restart dashboard

gluetun container stuck in "Created" state

Your host is missing the tun kernel module:

sudo modprobe tun
echo tun | sudo tee -a /etc/modules
sudo openbox restart media

License activation fails

License activation requires container egress to webhook.openbox.crushcodeworks.com. This is an optional Pro feature — free users can skip it.

qBittorrent password not working

Run the repair command:

sudo openbox repair media

ARR apps not downloading

  1. Check VPN is connected: sudo openbox doctor → VPN Tunnel
  2. Add an indexer in Prowlarr (without an indexer, requests queue forever)
  3. Check qBittorrent is connected to VPN

Updating OpenBox

Automatic Updates

OpenBox checks for updates daily. A notification appears in the dashboard when a new version is available.

Manual Update

sudo openbox update

Rollback

If an update causes issues, OpenBox automatically keeps a rollback copy:

sudo openbox rollback

Uninstall

This Destroys Everything

Uninstall removes all containers, data volumes, configs, and the OpenBox installation directory. There is no confirmation and no undo.

sudo openbox reset --nuke

This stops all containers, removes volumes, deletes /opt/openbox, and removes the openbox CLI.

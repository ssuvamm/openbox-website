Why OpenBox

Everything you need,
nothing you don't.

Built for people who want power without complexity. OpenBox handles the hard part so you can focus on what matters.

100% Private

All your data stays on your hardware. No cloud dependencies, no subscription fees, no tracking.

One-Command Install

curl the installer and go. Docker, firewall, SSL — everything configured automatically.

Auto-Updates + Rollback

Stay current without breaking things. Every update is atomic — if it fails, you're back in seconds.

NAS + VPS Compatible

UGREEN NAS, Synology, Raspberry Pi, or any VPS. One installer handles them all.

Media Stack Built-In

Sonarr, Radarr, Prowlarr, Jellyfin, qBittorrent — all pre-wired and auto-configured on day one.

Signed + Verified

Every release is SHA256-hashed and ed25519-signed. Supply-chain tamper detection built in.

VPN Optional

Media stack works with or without VPN. Enable VPN for encrypted torrent traffic, skip it for local networks.

Web Dashboard

Enable, disable, and manage every module from a beautiful web UI. No command-line required.
